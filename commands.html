Bot Commands

Everything you need to run flawless giveaways. All commands use modern Discord slash (/) integrations.

Command Description Usage Permissions
/gstart Starts a new giveaway in the current channel. /gstart [duration] [winners] [prize] Manage Server
/gend Immediately ends an ongoing giveaway. /gend [message_id] Manage Server
/greroll Selects a new winner for a completed giveaway. /greroll [message_id] Manage Server
/glist Displays all currently active giveaways. /glist Everyone
/gpause Pauses an active giveaway. /gpause [message_id] Manage Server
